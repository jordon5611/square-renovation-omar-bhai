# BATI - Tous Travaux du Bâtiment (Île-de-France)

Site web professionnel pour l'entreprise générale **BATI (SARL BATI 75)**, spécialisée dans tous travaux de rénovation du bâtiment en Île-de-France : Électricité, Peinture, Parquet, Carrelage, Placo et Plomberie.

## 🛠️ Stack Technique
- **React 18** + **TypeScript** + **Vite**
- **Tailwind CSS** + **Lucide Icons**
- **Leaflet** (Cartographie interactive des chantiers en Île-de-France)
- **Comparateur Avant / Après** interactif
- **Formulaire de Devis Multi-Étapes**
